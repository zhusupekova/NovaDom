# NovaDom

Сайт компании по ремонту квартир под ключ.

Публичный адрес после публикации GitHub Pages:

https://zhusupekova.github.io/NovaDom/

## Структура

- `site/` - статическая версия для GitHub Pages.
- `gh-pages` - ветка публикации GitHub Pages.
- `app/` - исходная Vinext-версия, использованная для локальной разработки.

GitHub Pages публикует содержимое ветки `gh-pages`.
